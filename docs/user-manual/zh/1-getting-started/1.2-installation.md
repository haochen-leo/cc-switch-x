# 1.2 安装指南

## 发布渠道与系统要求

CC Switch X 是非官方独立分叉。请只从 **[CC Switch X GitHub Releases](https://github.com/haochen-leo/cc-switch-x/releases)** 或本项目源码仓库获取 X 版本。上游官方 CC Switch 请访问 [ccswitch.io](https://ccswitch.io) 或 [farion1231/cc-switch](https://github.com/farion1231/cc-switch)。任何要求付费、充值或索取登录凭据的“CC Switch X”网站或客户端都不是本项目的发布渠道。

| 系统    | 最低版本                   | 架构                                |
| ------- | -------------------------- | ----------------------------------- |
| Windows | Windows 10 及以上          | x64                                 |
| macOS   | macOS 12 (Monterey) 及以上 | Intel (x64) / Apple Silicon (arm64) |
| Linux   | 见下方发行版说明           | x64 / ARM64                         |

## 前置要求

### 安装 Node.js

CC Switch X 管理的 CLI 工具（Claude Code、Codex、Gemini CLI）需要 Node.js 环境。

**推荐版本**：Node.js 18 LTS 或更高版本

#### Windows

1. 访问 [Node.js 官网](https://nodejs.org/)

2. 下载 LTS 版本安装包

3. 运行安装程序，按提示完成安装

4. 验证安装：

```bash
node --version
npm --version
```

#### macOS

```bash
# 使用 Homebrew 安装
brew install node

# 或使用 nvm（推荐）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

#### Linux

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# 或使用 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

### 安装 CLI 工具

#### Claude Code

**方式一：Homebrew（macOS 推荐）**

```bash
brew install claude-code
```

**方式二：npm**

```bash
npm install -g @anthropic-ai/claude-code

# 国内用户如下载慢，使用镜像源
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
```

#### Codex

**方式一：Homebrew（macOS 推荐）**

```bash
brew install codex
```

**方式二：npm**

```bash
npm install -g @openai/codex

# 国内用户如下载慢，使用镜像源
npm install -g @openai/codex --registry=https://registry.npmmirror.com
```

#### Gemini CLI

**方式一：Homebrew（macOS 推荐）**

```bash
brew install gemini-cli
```

**方式二：npm**

```bash
npm install -g @google/gemini-cli

# 国内用户如下载慢，使用镜像源
npm install -g @google/gemini-cli --registry=https://registry.npmmirror.com
```

> 💡 **提示**：如果经常遇到下载慢的问题，可以全局设置镜像源：
>
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```

## Windows

### 安装包方式

1. 访问 [Releases 页面](https://github.com/haochen-leo/cc-switch-x/releases)
2. 下载 `CC-Switch-X-v{版本号}-Windows.msi`
3. 双击运行安装程序
4. 按提示完成安装

注意：运行安装程序后如果没有任何反应，可以在文件上点击右键，在弹出的菜单中打开 `属性`，`常规`页中的 `安全` 勾选 `解除锁定`

### 绿色版（免安装）

1. 下载 `CC-Switch-X-v{版本号}-Windows-Portable.zip`
2. 解压到任意目录
3. 运行 `CC-Switch-X.exe`

## macOS

### 方式一：Homebrew

CC Switch X 尚未发布独立 Homebrew Cask。请使用下面的手动下载方式，或从源码构建。

### 方式二：手动下载

1. 下载 `CC-Switch-X-v{版本号}-macOS.dmg`（推荐）或 `CC-Switch-X-v{版本号}-macOS.zip`
2. 打开 DMG，或解压 zip 得到 `CC Switch X.app`
3. 拖动到「应用程序」文件夹

### Beta 签名状态

当前 CC Switch X Beta 构建尚未接入独立 Apple 签名与公证。macOS 可能显示 Gatekeeper 警告；请确认下载来源后再选择打开。

## Linux

### ArchLinux

CC Switch X 尚未发布独立 AUR 包。请使用 AppImage、deb/rpm 包，或从源码构建。

上游官方 `cc-switch-bin` 包安装的是官方 CC Switch，不是 CC Switch X。

### Debian / Ubuntu

1. 根据架构下载 `CC-Switch-X-v{版本号}-Linux-x86_64.deb` 或 `CC-Switch-X-v{版本号}-Linux-arm64.deb`
2. 安装：

```bash
sudo dpkg -i CC-Switch-X-v{版本号}-Linux-*.deb

# 如果有依赖问题
sudo apt-get install -f
```

### AppImage（通用）

1. 根据架构下载 `CC-Switch-X-v{版本号}-Linux-x86_64.AppImage` 或 `CC-Switch-X-v{版本号}-Linux-arm64.AppImage`
2. 添加执行权限：

```bash
chmod +x CC-Switch-X-v{版本号}-Linux-*.AppImage
```

3. 运行：

```bash
./CC-Switch-X-v{版本号}-Linux-*.AppImage
```

## 验证安装

安装完成后，启动 CC Switch X：

1. 应用窗口正常显示
2. 系统托盘出现 CC Switch X 图标
3. 应用切换器中能看到已启用的受管应用，并能切换到目标应用面板

## 自动更新

CC Switch X Beta 默认不启用自动更新：

- X 使用独立发布通道，不读取官方 CC Switch 更新清单
- 新版本请从 GitHub Releases 手动下载
- 后续配置 X 自有签名和更新通道后，再恢复应用内更新

也可以在「设置 → 关于」中查看当前版本和项目链接。

## 卸载

### Windows

- 通过「设置 → 应用」卸载
- 或运行安装目录下的卸载程序

### macOS

- 将 `CC Switch X.app` 移到废纸篓
- 可选：删除配置目录 `~/.cc-switch-x/`

### Linux

```bash
# Debian/Ubuntu
sudo apt remove cc-switch-x

# ArchLinux
# X 尚无官方 AUR 包；按你实际安装的包名卸载
```
