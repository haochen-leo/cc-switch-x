# 1.2 Installation Guide

## Release Channels and System Requirements

CC Switch X is an unofficial independent fork. Download X only from **[CC Switch X GitHub Releases](https://github.com/haochen-leo/cc-switch-x/releases)** or the project source repository. For upstream official CC Switch, use [ccswitch.io](https://ccswitch.io) or [farion1231/cc-switch](https://github.com/farion1231/cc-switch). Any "CC Switch X" site or client that asks for payment, top-ups, or login credentials is not a distribution channel for this project.

| System  | Minimum Version              | Architecture                        |
| ------- | ---------------------------- | ----------------------------------- |
| Windows | Windows 10 or later          | x64                                 |
| macOS   | macOS 12 (Monterey) or later | Intel (x64) / Apple Silicon (arm64) |
| Linux   | See distribution notes below | x64 / ARM64                         |

## Prerequisites

### Install Node.js

The CLI tools managed by CC Switch X (Claude Code, Codex, Gemini CLI) require a Node.js environment.

**Recommended version**: Node.js 18 LTS or higher

#### Windows

1. Visit the [Node.js official website](https://nodejs.org/)

2. Download the LTS version installer

3. Run the installer and follow the prompts

4. Verify installation:

```bash
node --version
npm --version
```

#### macOS

```bash
# Install with Homebrew
brew install node

# Or use nvm (recommended)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

#### Linux

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# Or use nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

### Install CLI Tools

#### Claude Code

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install claude-code
```

**Option 2: npm**

```bash
npm install -g @anthropic-ai/claude-code
```

#### Codex

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install codex
```

**Option 2: npm**

```bash
npm install -g @openai/codex
```

#### Gemini CLI

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install gemini-cli
```

**Option 2: npm**

```bash
npm install -g @google/gemini-cli
```

## Windows

### Installer

1. Visit the [Releases page](https://github.com/haochen-leo/cc-switch-x/releases)
2. Download `CC-Switch-X-v{version}-Windows.msi`
3. Double-click to run the installer
4. Follow the prompts to complete installation

### Portable Version (No Installation Required)

1. Download `CC-Switch-X-v{version}-Windows-Portable.zip`
2. Extract to any directory
3. Run `CC-Switch-X.exe`

## macOS

### Option 1: Homebrew

CC Switch X does not have a dedicated Homebrew Cask yet. Use the manual download below or build from source.

### Option 2: Manual Download

1. Download `CC-Switch-X-v{version}-macOS.dmg` (recommended) or `CC-Switch-X-v{version}-macOS.zip`
2. Open the DMG, or extract the zip to get `CC Switch X.app`
3. Drag it to the Applications folder

### Beta Signing Status

The current CC Switch X beta is not signed or notarized with an X-specific Apple certificate yet. macOS may show a Gatekeeper warning; verify the download source before choosing to open it.

## Linux

### ArchLinux

CC Switch X does not have a dedicated AUR package yet. Use the AppImage, deb/rpm packages, or build from source.

The upstream `cc-switch-bin` package installs official CC Switch, not CC Switch X.

### Debian / Ubuntu

1. Download `CC-Switch-X-v{version}-Linux-x86_64.deb` or `CC-Switch-X-v{version}-Linux-arm64.deb` for your architecture
2. Install:

```bash
sudo dpkg -i CC-Switch-X-v{version}-Linux-*.deb

# If there are dependency issues
sudo apt-get install -f
```

### AppImage (Universal)

1. Download `CC-Switch-X-v{version}-Linux-x86_64.AppImage` or `CC-Switch-X-v{version}-Linux-arm64.AppImage` for your architecture
2. Add execute permission:

```bash
chmod +x CC-Switch-X-v{version}-Linux-*.AppImage
```

3. Run:

```bash
./CC-Switch-X-v{version}-Linux-*.AppImage
```

## Verify Installation

After installation, launch CC Switch X:

1. The app window displays correctly
2. A CC Switch X icon appears in the system tray
3. The app switcher shows enabled managed apps, and you can switch to the target app panel

## Auto Update

CC Switch X beta builds do not enable the automatic updater:

- X uses an independent release channel and does not read the official CC Switch update manifest
- Download new versions manually from GitHub Releases
- In-app updates will return after X-specific signing and update infrastructure are configured

You can view the current version and project links in "Settings > About".

## Uninstall

### Windows

- Uninstall via "Settings > Apps"
- Or run the uninstaller in the installation directory

### macOS

- Move `CC Switch X.app` to Trash
- Optional: Delete the configuration directory `~/.cc-switch-x/`

### Linux

```bash
# Debian/Ubuntu
sudo apt remove cc-switch-x

# ArchLinux
# X does not have an official AUR package yet; uninstall the package name you installed
```
