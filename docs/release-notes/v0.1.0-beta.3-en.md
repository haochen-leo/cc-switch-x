# CC Switch X v0.1.0-beta.3

**Release date**: 2026-09-07

**[中文版 →](v0.1.0-beta.3-zh.md) | [日本語版 →](v0.1.0-beta.3-ja.md)**

CC Switch X v0.1.0-beta.3 refreshes the Codex bridge layer released in
`v0.1.0-beta.2`.

## Highlights

- Repairs standalone `function_call_output` replay pairing across the
  Responses, Chat, and Anthropic bridge paths.
- Adds aggregate route fallback for local compaction requests.
- Replaces the recursive `automation_update` tool schema with a flattened
  schema on third-party native Responses routes.
- Splits native Responses transformation logic into a dedicated provider
  module.

## Upgrade and rollback

- X keeps its runtime data under `~/.cc-switch-x` and does not overwrite the
  official `~/.cc-switch` database.
- This beta does not enable the official updater channel.
- The manually built macOS package is unsigned and not notarized. Verify the
  package provenance before opening it and expect a Gatekeeper warning.
