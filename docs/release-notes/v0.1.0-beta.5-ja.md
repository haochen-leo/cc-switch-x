# CC Switch X v0.1.0-beta.5

**リリース日**: 2026-09-18

**[English →](v0.1.0-beta.5-en.md) | [中文版 →](v0.1.0-beta.5-zh.md)**

CC Switch X v0.1.0-beta.5 はプロキシ経路にメディア OCR を導入し、
モデル単位の集約フィルタ、モデルごとの画像対応宣言、利用状況ビューの
出力トークン速度表示を追加しました。

## ハイライト

- **メディア OCR**: プロキシがメディア OCR リクエストを記録し、OCR
  プリフライトを実行、DeepSeek flash 0731 では OCR をトリガーします。
  ネイティブのビジョン機能を持たないモデルでも画像コンテンツを
  テキストとして扱えます。
- **モデル単位の集約フィルタ**: Codex 集約がモデル単位のフィルタに
  対応し、プロバイダごとに集約するモデルを選択できます。
- **モデルごとの画像対応宣言**: プロバイダフォームにモデル単位で
  画像対応を宣言する専用コントロールを追加しました。
- **出力速度**: 利用状況ビューが完了済みリクエストの出力
  tokens/秒を表示します。
- **ツール検索コントラクト**: ブリッジパス間の書き換え時に Codex の
  ツール検索コントラクトを保持し、リプレイベースから失われていた
  xAI 厳格サニタイザーのテストを復元しました。

## アップグレードとロールバック

- X の実行データは `~/.cc-switch-x` に保存され、公式
  `~/.cc-switch` データベースを上書きしません。
- 本ベータでは公式の自動更新チャネルは有効になりません。
- 手動ビルドの macOS パッケージは署名・公証されていません。開く前に
  パッケージの出所を確認し、Gatekeeper の警告が表示されることを
  想定してください。

変更の完全な一覧は[更新履歴](../../CHANGELOG.md)を参照してください。
