# CC Switch X v0.1.0-beta.9

本版让 Codex 多模型聚合中的第三方父模型默认使用经典 V1 子代理工具，跨服务商拆任务时更稳定。

- 新增 `codexStackClassicTools` 设置（默认开启）：聚合路由下，第三方父模型生成的目录条目统一使用 `multi_agent_version: v1`。
- 厂商官方目录条目（如 DeepSeek 官方模型）保持原样，保留其自带的 agent 版本元数据，不被覆盖。
- 开关暴露在聚合来源下拉菜单中，切换后立即重建聚合目录；重建失败自动回滚到之前的状态。

数据库结构、代理协议和端口不变。升级前退出 CC Switch X，备份整个 `~/.cc-switch-x`。
安装后 X 会刷新并发布聚合目录；已运行的 Codex 若未重新读取静态目录，需要在合适时机新开客户端，勿中断正在执行的会话。

所有安装包由 GitHub Actions 构建并提供 `SHA256SUMS.txt`。macOS 使用 ad-hoc 签名、未公证；自动更新仍关闭。
