# CC Switch X v0.1.0-beta.9

This release makes third-party parent models in Codex multi-model aggregation default to the classic V1 subagent tools, improving stability for cross-provider task delegation.

- New `codexStackClassicTools` setting (on by default): in routed-aggregate mode, generated catalog entries for third-party parent models use `multi_agent_version: v1`.
- Vendor official catalog entries (e.g. DeepSeek official models) are kept verbatim, preserving their own agent version metadata.
- The toggle lives in the aggregation source-providers dropdown; switching rebuilds the aggregate catalog immediately and rolls back automatically on failure.

Database schema, proxy protocols, and ports are unchanged. Quit CC Switch X and back up the entire `~/.cc-switch-x` directory before upgrading.
After installation, X refreshes and publishes the aggregate catalog; a running Codex client that has not re-read the static catalog should be restarted at a safe point — do not interrupt an active session.

All installers are built by GitHub Actions with `SHA256SUMS.txt` provided. macOS builds use ad-hoc signing without notarization; auto-update remains disabled.
