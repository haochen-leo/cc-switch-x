# CC Switch X v0.1.0-beta.7

**发布日期**：2026-10-24

**[English →](v0.1.0-beta.7-en.md) | [日本語版 →](v0.1.0-beta.7-ja.md)**

本版修复 beta.6 构建中 Windows MSI 无法接受 `beta.6` 预发布字符串的问题。
应用版本为 `0.1.0-beta.7`，MSI 安装器单独使用数字版本 `0.1.0.7`。
beta.6 标签保持不变，该版本未发布完整 Release。

同时修正 macOS 通用包架构校验命令的参数顺序；签名和双架构校验继续执行。

功能及数据库结构不变，继续保留官方 3.20.4 基线上的模型聚合、路由、视觉/OCR、
协议桥接、本地 compaction，以及 X 独立产品标识和数据目录。
完整功能与迁移说明见 [beta.6 版本说明](v0.1.0-beta.6-zh.md)。

所有安装包由 GitHub Actions 构建并附 `SHA256SUMS.txt`，提供 macOS 通用 DMG/ZIP、
Windows x64/ARM64 MSI 及便携 ZIP、Linux x64/ARM64 AppImage/DEB/RPM。
macOS 仅使用 ad-hoc 签名、未公证；Windows 无代码签名。应用自动更新仍关闭。

更新前请退出应用并备份整个 `~/.cc-switch-x`；旧本地安装仍使用 `~/.cc-switch`
时，请先阅读[迁移与隔离边界](../cc-switch-x-maintenance-zh.md)。
