# CC Switch X v0.1.0-beta.7

**Release date**: 2026-10-24

**[中文版 →](v0.1.0-beta.7-zh.md) | [日本語版 →](v0.1.0-beta.7-ja.md)**

Fixes Windows MSI packaging rejecting the `beta.6` prerelease string.
The application version is `0.1.0-beta.7`; MSI uses the separate numeric
installer version `0.1.0.7`. The beta.6 tag is unchanged; no complete Release
was published for it.

Also corrects the argument order in macOS universal-package verification.
Signature and dual-architecture checks remain enabled.

Features and database schemas are unchanged. Model aggregation, routing,
vision/OCR, protocol bridges, local compaction, and X product/data isolation
remain available on the upstream 3.20.4 baseline. See the
[beta.6 notes](v0.1.0-beta.6-en.md) for full feature and migration details.

GitHub Actions builds all packages and includes `SHA256SUMS.txt`: universal
macOS DMG/ZIP, Windows x64/ARM64 MSI and portable ZIP, and Linux x64/ARM64
AppImage/DEB/RPM. macOS has only ad-hoc signing, without notarization;
Windows has no code signature. Automatic updates remain disabled.

Quit the app and back up all of `~/.cc-switch-x` before upgrading. Older local
installations using `~/.cc-switch` should first read the
[migration and isolation policy](../cc-switch-x-maintenance.md).
