# CC Switch X v0.1.0-beta.5

**Release date**: 2026-09-18

**[中文版 →](v0.1.0-beta.5-zh.md) | [日本語版 →](v0.1.0-beta.5-ja.md)**

CC Switch X v0.1.0-beta.5 adds media OCR to the proxy pipeline, model-level
aggregation filters, per-model image support declarations, and output token
speed in usage views.

## Highlights

- **Media OCR**: The proxy now records media OCR requests, runs an OCR
  preflight, and triggers OCR for DeepSeek flash 0731, so image content can
  be turned into text for models without native vision support.
- **Model-Level Aggregation Filters**: Codex aggregation now supports
  per-model filters, letting a provider aggregate only the models you
  choose.
- **Per-Model Image Support Declarations**: Provider forms gain a dedicated
  control to declare image support per model, driving OCR behavior for
  vision-less models.
- **Usage Output Speed**: Usage views now show output tokens per second for
  completed requests.
- **Tool Search Contract**: Codex tool search contract preserved when
  rewriting between bridge paths; the xAI strict-sanitizer test dropped from
  the replay base is restored.

## Upgrade and rollback

- X keeps its runtime data under `~/.cc-switch-x` and does not overwrite the
  official `~/.cc-switch` database.
- This beta does not enable the official updater channel.
- The manually built macOS package is unsigned and not notarized. Verify the
  package provenance before opening it and expect a Gatekeeper warning.
