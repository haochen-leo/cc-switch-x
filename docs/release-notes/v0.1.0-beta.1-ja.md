# CC Switch X v0.1.0-beta.1

**リリース日**: 2026-08-31

**[English →](v0.1.0-beta.1-en.md) | [中文版 →](v0.1.0-beta.1-zh.md)**

CC Switch X は [CC Switch](https://github.com/farion1231/cc-switch) の非公式
独立フォークです。現在の基線は上流 `d8065cc6`（CC Switch 3.20.1）です。

## 主な変更

- Claude のマルチプロバイダルーティングと、モデル役割ごとの独立マッピング。
- 公式モデルとサードパーティモデルを同じ選択画面に集約し、シームレスに
  切り替えられる Codex マルチプロバイダ対応。
- プロバイダごとに異なる Codex Responses プロトコル意味論への互換性強化。
- 429 レート制限処理とプロバイダフェイルオーバーを含む長時間セッションの
  堅牢性向上。
- 独立した製品 identity: `CC Switch X`、パッケージ名 `cc-switch-x`、
  Bundle ID `io.github.haochen-leo.ccswitchx`、Deep Link スキーム
  `ccswitchx://`。
- 実行データを `~/.cc-switch-x` に分離し、公式版の `~/.cc-switch`
  データベースは変更しません。
- 初回起動時に互換性のある公式データベースから読み取り専用で設定を
  インポートし、双方に存在する共通列のみをコピーします。
- X 固有の状態は `x_` テーブルに保存し、上流の
  `PRAGMA user_version` マイグレーションとは独立して管理します。
- 既定のローカルプロキシポートは `15722` で、公式版の既定 `15721` と
  衝突しません。
- 新規生成リンクは `ccswitchx://` を使用し、既存の `ccswitch://`
  インポートリンクも引き続き解析できます。

## 含まれる上流基線

この Beta には上流 CC Switch 3.20.1 が含まれます。上流のリリースノート:

- [上流 CC Switch v3.20.1](v3.20.1-ja.md)

また、X 開発ブランチの Codex/プロキシ機能（Codex プロキシ、Responses
変換、ルーティング、再試行、ログ、使用量、関連 UI）を保持しています。

## アップグレードとロールバック

- X は公式版の実行データベースを共有・上書きしません。
- 初回起動時に、互換データを `~/.cc-switch` から `~/.cc-switch-x` へ
  インポートできます。
- 元の `~/.cc-switch` は保持されるため、ロールバックに利用できます。
- 両方のアプリで同じクライアントのプロキシ接管を同時に有効にしないで
  ください。どちらも CLI の live 設定を書き込む可能性があり、最後の
  書き込みが有効になります。

## リリースチャネル状態

これは Beta リリースです。公式 CC Switch の updater および署名チャネルは
使用しません。X 固有の署名とリリース基盤が整うまで、自動更新成果物は
無効のままです。

ダウンロードは次の場所のみから行ってください:

- <https://github.com/haochen-leo/cc-switch-x/releases>

初期のローカル macOS ビルドは未署名・未公証です。開く前に配布元を確認し、
macOS の Gatekeeper 警告が表示される可能性を前提としてください。

## 既知の境界

- 互換性のある公式データベースのみをインポートします。未対応の新しい上流
  schema はスキップされますが、X 自身のデータベース作成は妨げられません。
- X 拡張テーブルはまだ公式クラウド同期ペイロードに含まれません。
- Linux Flatpak メタデータと完全なマルチプラットフォームリリース
  パイプラインは、X identity では未検証です。
