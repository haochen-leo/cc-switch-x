# CC Switch X v0.1.0-beta.3

**リリース日**: 2026-09-07

**[English →](v0.1.0-beta.3-en.md) | [中文版 →](v0.1.0-beta.3-zh.md)**

CC Switch X v0.1.0-beta.3 は `v0.1.0-beta.2` の Codex ブリッジ互換層を
さらに更新する Beta です。

## 主な変更

- Responses、Chat、Anthropic の各ブリッジで孤立した
  `function_call_output` replay ペアを修復します。
- ローカル compaction リクエスト向けに aggregate route のフォールバックを
  追加します。
- サードパーティ Native Responses ルートで、再帰的な
  `automation_update` ツール schema を扁平化します。
- Native Responses 変換ロジックを専用 provider モジュールへ分割します。

## アップグレードとロールバック

- X の実行データは `~/.cc-switch-x` に保存され、公式版の
  `~/.cc-switch` データベースを上書きしません。
- この Beta では公式 updater チャネルを有効にしていません。
- 手動で作成した macOS パッケージは未署名・未公証です。開く前に配布元を
  確認し、Gatekeeper 警告が表示される可能性を前提としてください。

完全な変更一覧は[更新履歴](../../CHANGELOG.md)を参照してください。
