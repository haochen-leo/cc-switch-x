# CC Switch X v0.1.0-beta.4

**发布日期**：2026-09-13

**[English →](v0.1.0-beta.4-en.md) | [日本語版 →](v0.1.0-beta.4-ja.md)**

CC Switch X v0.1.0-beta.4 将 Codex 通用配置统一收纳到官方 provider 之下，
代理覆盖扩展到 Codex 图像端点，并将上游 CC Switch 基线同步至 v3.20.2
系列。

## 本版重点

- Codex 通用配置统一归属官方 provider：启动时实时捕获并带防污染保护，
  界面中官方配置为只读，实时重写时保留非数据库管理的 `mcp_servers`。
- 代理覆盖 Codex 图像生成（image generations）与图像编辑（image edits）
  端点。
- 聚合安全：聚合激活期间禁用 provider 切换，内置官方种子 provider 不可
  删除，接管期间 Codex `/v1/models` 探测请求中继到官方后端。
- 同步回放与终态对齐；移除重复的 Mac raw-relay 图像路由，改用上游独立
  透传。
- 上游同步：新增 SoleAPI、9527CODE、AICodeWith、QwenCloud、腾讯
  TokenHub / Token Plan 预设，扩展 PPIO Pi 预设；2026 年 9 月价格表刷新
  （GPT-6 Astra、GLM-5.3 / GLM-5.3 Flash、Gemini 3.8 Flash、Claude
  Fable 5.1 / Mythos 5.1）；Grok/xAI Native Responses 修复；Codex
  OAuth 并行工具调用；更新失败提示显示真实原因；以及若干 i18n 与
  无障碍修复。

## 升级与回滚

- X 的运行数据位于 `~/.cc-switch-x`，不会覆盖官方
  `~/.cc-switch` 数据库。
- 本 Beta 不启用官方自动更新通道。
- 手工构建的 macOS 制品未签名、未公证。打开前请确认制品来源，并预期
  可能出现 Gatekeeper 警告。

完整变更请参阅[更新日志](../../CHANGELOG.md)。
