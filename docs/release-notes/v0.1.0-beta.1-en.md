# CC Switch X v0.1.0-beta.1

**Release date**: 2026-08-31

**[中文版 →](v0.1.0-beta.1-zh.md) | [日本語版 →](v0.1.0-beta.1-ja.md)**

CC Switch X is an unofficial, independently branded fork of
[CC Switch](https://github.com/farion1231/cc-switch), based on upstream
`d8065cc6` (CC Switch 3.20.1).

## Highlights

- Claude multi-provider routing with independent model-role mapping.
- Codex model aggregation that places official and third-party models in one
  picker and keeps switching between them seamless.
- Compatibility hardening for provider-specific deviations from Codex's
  Responses protocol semantics.
- Resilience for long sessions, including 429 rate-limit handling and
  provider failover.
- Independent product identity: `CC Switch X`, package `cc-switch-x`, bundle ID
  `io.github.haochen-leo.ccswitchx`, and deep-link scheme `ccswitchx://`.
- Isolated runtime data under `~/.cc-switch-x`; the official `~/.cc-switch`
  database is never modified.
- First-run import from a compatible official database, using read-only SQLite
  access and copying only columns shared by both schemas.
- X-specific state is stored in `x_` tables and tracked separately from the
  upstream `PRAGMA user_version` migration chain.
- Default local proxy port is `15722`, avoiding collisions with the official
  app's default `15721`.
- Legacy `ccswitch://` imports remain accepted, while new generated links use
  `ccswitchx://`.

## Included Baseline

This beta includes the upstream CC Switch 3.20.1 baseline. See the imported
upstream notes:

- [Upstream CC Switch v3.20.1](v3.20.1-en.md)

It also retains the local Codex/proxy feature set carried by the X development
branch, including the Codex proxy, Responses conversion, routing, retry,
logging, usage, and related UI work.

## Upgrade and Rollback

- X does not share or overwrite the official runtime database.
- On first launch, compatible data can be imported from `~/.cc-switch` into
  `~/.cc-switch-x`.
- The original `~/.cc-switch` directory remains available for rollback.
- Do not run both apps with proxy takeover enabled for the same client at the
  same time; both products can still write live CLI configuration files.

## Release Channel Status

This is a beta release. The official CC Switch updater and signing channel are
not used. CC Switch X updater artifacts remain disabled until X-specific
signing and release infrastructure are configured.

Download only from:

- <https://github.com/haochen-leo/cc-switch-x/releases>

The initial local macOS build is unsigned and not notarized. Verify provenance
before opening it, and expect a Gatekeeper warning on macOS.

## Known Boundaries

- X imports compatible official databases only. A newer unsupported upstream
  schema is skipped without blocking X from creating its own database.
- X-specific extension tables are not part of the official cloud-sync payload
  yet.
- Linux Flatpak metadata and the full multi-platform release pipeline are not
  yet validated for the X identity.
