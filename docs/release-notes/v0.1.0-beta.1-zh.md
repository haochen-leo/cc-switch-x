# CC Switch X v0.1.0-beta.1

**发布日期**：2026-08-31

**[English →](v0.1.0-beta.1-en.md) | [日本語版 →](v0.1.0-beta.1-ja.md)**

CC Switch X 是 [CC Switch](https://github.com/farion1231/cc-switch) 的非官方
独立分叉，当前基于上游 `d8065cc6`（CC Switch 3.20.1）。

## 本版重点

- Claude 多供应商路由，可按模型角色独立映射。
- Codex 多供应商模型聚合，将官方与第三方模型放入同一个选择器，并保持
  无缝切换。
- 针对不同供应商偏离 Codex Responses 协议语义的情况增强兼容性。
- 加强长会话健壮性，包括 429 限流处理与供应商故障转移。
- 使用独立产品身份：`CC Switch X`、包名 `cc-switch-x`、Bundle ID
  `io.github.haochen-leo.ccswitchx`、Deep Link 协议 `ccswitchx://`。
- 运行数据隔离到 `~/.cc-switch-x`，不会修改官方版本的 `~/.cc-switch`
  数据库。
- 首次启动可从兼容的官方数据库只读导入配置，仅复制双方 schema 共有的列。
- X 扩展状态写入 `x_` 表，并由独立元数据记录，不占用上游
  `PRAGMA user_version` 迁移链。
- 默认本地代理端口改为 `15722`，避免与官方默认 `15721` 冲突。
- 新生成的链接使用 `ccswitchx://`，同时继续兼容解析旧的
  `ccswitch://` 导入链接。

## 包含的上游基线

本 Beta 包含上游 CC Switch 3.20.1 基线。上游发布说明见：

- [上游 CC Switch v3.20.1](v3.20.1-zh.md)

同时保留 X 开发分支中的本地 Codex/代理能力，包括 Codex 代理、Responses
转换、路由、重试、日志、用量统计及相关界面能力。

## 升级与回滚

- X 不共用、不覆盖官方运行数据库。
- 首次启动时可将兼容数据从 `~/.cc-switch` 导入到 `~/.cc-switch-x`。
- 原 `~/.cc-switch` 目录保持不动，可用于回滚。
- 不建议两个应用同时对同一个客户端开启代理接管；两者仍可能按用户操作
  写入同一个 CLI 实时配置文件，最后写入者生效。

## 发布通道状态

这是 Beta 版本。CC Switch X 不使用官方 CC Switch 的更新器和签名通道；
在 X 自己的签名与发布基础设施配置完成前，自动更新产物保持关闭。

请只从以下地址下载：

- <https://github.com/haochen-leo/cc-switch-x/releases>

当前本地 macOS 构建未签名、未公证。打开前请确认来源，并预期 macOS 可能
出现 Gatekeeper 警告。

## 已知边界

- 仅支持导入兼容版本的官方数据库；更高版本的上游 schema 会被跳过，但不
  会阻止 X 创建自己的数据库。
- X 扩展表尚未加入官方云同步载荷。
- Linux Flatpak 元数据和完整多平台发布流水线尚未按 X 身份完成验证。
