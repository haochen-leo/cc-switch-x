# CC Switch X v0.1.0-beta.11

本版补齐 Codex Responses 链路对行内 thinking 的兼容，并修复两处小问题。

- 新增 think 块修复：当上游把助手消息写成行内 `<think>…</think>` 前缀文本时，X 会将其拆分为独立的 reasoning 项，与原生 Responses 表示一致，正文不再夹带思考内容。缓冲响应与 SSE 流两种路径同时生效；未闭合或不完整的块保持原样透传。
- 修复 Codex 客户端升级后官方模型目录被清空、需要重新拉取的问题：目录缓存现在跨客户端版本复用。
- 修复用量表中 token 列重复显示输出速度的问题。

数据库结构、代理协议和端口不变。升级前退出 CC Switch X，备份整个 `~/.cc-switch-x`。
所有安装包由 GitHub Actions 构建并提供 `SHA256SUMS.txt`。macOS 使用 ad-hoc 签名、未公证；Windows 安装包尚未使用代码签名证书。
