# CC Switch X v0.1.0-beta.4

**Release date**: 2026-09-13

**[中文版 →](v0.1.0-beta.4-zh.md) | [日本語版 →](v0.1.0-beta.4-ja.md)**

CC Switch X v0.1.0-beta.4 unifies Codex common configuration under the
official provider, extends proxy coverage to Codex image endpoints, and
syncs the upstream CC Switch baseline through the v3.20.2 line.

## Highlights

- Codex common settings now live under the official provider: captured live
  at startup with an anti-poisoning guard, shown read-only in the UI, and
  non-database `mcp_servers` entries survive live rewrites.
- The proxy now covers the Codex image generations and image edits
  endpoints.
- Aggregation safety: provider switching is disabled while aggregation is
  active, built-in official seed providers can no longer be deleted, and
  Codex `/v1/models` probes are relayed to the official backend during
  takeover.
- Sync replay now reconciles with terminal states, and duplicate Mac
  raw-relay image routes are dropped in favor of upstream standalone
  passthrough.
- Upstream sync: new presets for SoleAPI, 9527CODE, AICodeWith, QwenCloud,
  Tencent TokenHub / Token Plan, and extended PPIO Pi presets; September
  2026 pricing refresh (GPT-6 Astra, GLM-5.3 / GLM-5.3 Flash, Gemini 3.8
  Flash, Claude Fable 5.1 / Mythos 5.1); Grok/xAI native Responses fixes;
  parallel tool calls for Codex OAuth; clearer updater failure reasons; and
  assorted i18n and accessibility fixes.

## Upgrade and rollback

- X keeps its runtime data under `~/.cc-switch-x` and does not overwrite the
  official `~/.cc-switch` database.
- This beta does not enable the official updater channel.
- The manually built macOS package is unsigned and not notarized. Verify the
  package provenance before opening it and expect a Gatekeeper warning.
