# CC Switch X v0.1.0-beta.11

This release adds compatibility for inline thinking on the Codex Responses path and fixes two minor issues.

- New think-block repair: when an upstream provider writes an assistant message as text prefixed with an inline `<think>…</think>` block, X splits the thinking into a separate reasoning item, matching the native Responses representation, so the visible answer no longer carries raw thinking text. Applies to both buffered responses and SSE streams; unterminated or incomplete blocks pass through unchanged.
- Fixed the official model catalog being wiped after a Codex client upgrade: the catalog cache is now reused across client versions.
- Fixed the token column in the usage table showing output speed twice.

Database schema, proxy protocols, and ports are unchanged. Quit CC Switch X and back up the entire `~/.cc-switch-x` directory before upgrading.
All installers are built by GitHub Actions with `SHA256SUMS.txt` provided. macOS builds use ad-hoc signing without notarization; Windows installers are not yet signed with a code-signing certificate.
