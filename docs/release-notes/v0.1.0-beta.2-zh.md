# CC Switch X v0.1.0-beta.2

**发布日期**：2026-09-07

**[English →](v0.1.0-beta.2-en.md) | [日本語版 →](v0.1.0-beta.2-ja.md)**

CC Switch X v0.1.0-beta.2 是一个维护型 Beta，重点修复 Codex 协议兼容性、
聚合模型目录语义和测试配置隔离问题。

## 本版重点

- 为孤立的 `codex_app` `function_call_output` 回放补齐完整且确定性的
  function-call 配对。
- 官方模型目录条目保持原样，第三方路由统一使用 X 模板。
- 测试配置在测试目录变量暂时缺失时不再回退写入真实用户目录。
- 增加 Codex 接管配置的路由键诊断日志。

## 升级与回滚

- X 的运行数据位于 `~/.cc-switch-x`，不会覆盖官方
  `~/.cc-switch` 数据库。
- 本 Beta 不启用官方自动更新通道。
- 手工构建的 macOS 制品未签名、未公证。打开前请确认制品来源，并预期
  可能出现 Gatekeeper 警告。

完整变更请参阅[更新日志](../../CHANGELOG.md)。
