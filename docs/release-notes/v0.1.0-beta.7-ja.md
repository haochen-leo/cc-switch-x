# CC Switch X v0.1.0-beta.7

**リリース日**: 2026-10-24

**[English →](v0.1.0-beta.7-en.md) | [中文版 →](v0.1.0-beta.7-zh.md)**

Windows MSI が `beta.6` のプレリリース文字列を受け付けず、ビルドに失敗する問題を修正。
アプリは `0.1.0-beta.7`、MSI インストーラーは別の数値バージョン `0.1.0.7` を使用します。
beta.6 タグは変更せず、同版の完全な Release は公開していません。

macOS 共通パッケージのアーキテクチャ確認コマンドの引数順も修正。
署名と両アーキテクチャの検証は引き続き実行します。

機能とデータベース構造は変更しません。公式 3.20.4 を基盤とするモデル集約、ルーティング、
画像/OCR、プロトコル変換、ローカル compaction、X の製品・データ分離を保持します。
詳細は [beta.6 の説明](v0.1.0-beta.6-ja.md)を参照してください。

全パッケージは GitHub Actions でビルドし、`SHA256SUMS.txt` を同梱します。
macOS 共通 DMG/ZIP、Windows x64/ARM64 MSI・ZIP、Linux x64/ARM64 AppImage・DEB・RPM を提供。
macOS は ad-hoc 署名のみで公証なし、Windows はコード署名なしです。自動更新は無効のままです。

更新前にアプリを終了し、`~/.cc-switch-x` 全体をバックアップしてください。
旧ローカル版が `~/.cc-switch` を使用する場合は、先に
[移行・分離方針](../cc-switch-x-maintenance.md)を確認してください。
