# CC Switch X v0.1.0-beta.6

**Release date**: 2026-10-23

**[中文版 →](v0.1.0-beta.6-zh.md) | [日本語版 →](v0.1.0-beta.6-ja.md)**

This release uses official CC Switch 3.20.4 as its upstream baseline, preserves
the individual X commits and local capabilities, aligns product isolation and
database extensions, and consolidates the development and release branches.

## Highlights

- **Aggregation and routing preserved**: Claude role-based provider mapping,
  Codex multi-provider model aggregation, model filters, 429 retries, request
  logging, and usage accounting remain available.
- **Vision and OCR**: Per-model image declarations, image budgets, and OCR
  caching remain available. DeepSeek V4.1 is not classified as text-only just
  because of its prefix; the known text-only list and explicit user declarations
  determine image-to-text handling.
- **Protocol compatibility**: Chat, Anthropic, and Responses bridges retain
  tool-search semantics and Codex local compaction on Chat/Anthropic routes.
- **X isolation**: Bundle ID `io.github.haochen-leo.ccswitchx` and runtime data
  under `~/.cc-switch-x`; the official runtime database is not shared.
- **Database alignment**: Shared schema v20 retains upstream MCode fields and
  X OCR caching. Independent X schema v2 stores retry settings and import history
  in extension tables.
- **Branches**: `main` is X development, `release` is the release line, and tags
  pin published commits. Upstream 3.20.4 is not the X release version.

## Installation and upgrade

- These assets are **macOS Apple Silicon only (arm64, macOS 12+)**, provided as
  DMG and ZIP with `SHA256SUMS.txt`. No Intel, Windows, or Linux packages are
  included in this release.
- The app has a local ad-hoc signature, **not an Apple Developer ID signature
  or notarization**. Expect a possible Gatekeeper warning and verify provenance
  and SHA256 before opening.
- Existing `~/.cc-switch-x` users should quit the app and back up that directory
  before replacing the application.
- Older local installations still using `~/.cc-switch` need a full-directory
  backup and complete database/settings migration while the app is stopped.
  The read-only first-run importer is selective and does not migrate all history.
  See the [migration and isolation policy](../cc-switch-x-maintenance.md).
- New installations default to proxy port `15722`; existing installations may
  keep their active port.
- Neither the official updater nor an unsigned X updater channel is enabled.
  Restore the matching data backup before rolling back; do not open an upgraded
  database with an older version directly.
