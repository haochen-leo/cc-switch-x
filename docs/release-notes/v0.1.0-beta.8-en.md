# CC Switch X v0.1.0-beta.8

Fixes stale, truncated official model catalogs in Codex multi-provider aggregation.

- Select the newest locally observed semantic client version from PATH, recent threads and native cache metadata. No CLI upgrade or hard-coded request version.
- Fetch using the current login. Bind the X snapshot to user, workspace and client version; use the native cache only as a version hint, never as catalog content.
- Share one snapshot across the menu, generated catalog, routes and publication hash. Failed publication remains retryable even when the next fetch is unchanged.
- Count visible models separately from saved exclusions. Preserve exclusion choices and honor model removals from successful upstream responses.

No database, proxy protocol or port changes. Quit CC Switch X and back up `~/.cc-switch-x` before installing. Existing Codex clients may need to reload the static catalog at a convenient time; do not interrupt active sessions.

Packages are built by GitHub Actions with SHA-256 checksums. macOS builds are ad-hoc signed, not notarized. Automatic updates remain disabled.
