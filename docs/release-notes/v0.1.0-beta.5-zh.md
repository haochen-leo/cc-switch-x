# CC Switch X v0.1.0-beta.5

**发布日期**：2026-09-18

**[English →](v0.1.0-beta.5-en.md) | [日本語版 →](v0.1.0-beta.5-ja.md)**

CC Switch X v0.1.0-beta.5 为代理链路引入媒体 OCR，新增模型级聚合过滤、
逐模型图像能力声明，以及用量视图的输出 token 速度展示。

## 本版重点

- **媒体 OCR**：代理现在会记录媒体 OCR 请求、执行 OCR 预检，并对
  DeepSeek flash 0731 触发 OCR，让不具备视觉能力的模型也能处理图像
  内容（转为文本）。
- **模型级聚合过滤**：Codex 聚合支持逐模型过滤，可以让一个 provider
  只聚合你选择的模型。
- **逐模型图像能力声明**：Provider 表单新增独立控件按模型声明图像
  支持，用于驱动无视觉模型的 OCR 行为。
- **输出速度**：用量视图现在为已完成的请求展示输出 tokens/秒。
- **工具搜索契约**：桥接路径改写时保留 Codex 工具搜索契约；恢复从
  replay 基线中丢失的 xAI 严格清洗器测试。

## 升级与回滚

- X 的运行数据位于 `~/.cc-switch-x`，不会覆盖官方
  `~/.cc-switch` 数据库。
- 本 Beta 不启用官方自动更新通道。
- 手工构建的 macOS 制品未签名、未公证。打开前请确认制品来源，并预期
  可能出现 Gatekeeper 警告。

完整变更请参阅[更新日志](../../CHANGELOG.md)。
