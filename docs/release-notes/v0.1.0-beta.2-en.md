# CC Switch X v0.1.0-beta.2

**Release date**: 2026-09-07

**[中文版 →](v0.1.0-beta.2-zh.md) | [日本語版 →](v0.1.0-beta.2-ja.md)**

CC Switch X v0.1.0-beta.2 is a maintenance beta focused on Codex protocol
compatibility, aggregate model-catalog correctness, and safer test isolation.

## Highlights

- Repairs orphan `codex_app` `function_call_output` replays with a complete,
  deterministic function-call pair.
- Keeps official catalog entries verbatim while applying the shared X template
  to third-party routes.
- Prevents test configuration writes from falling back to the real user home.
- Adds route-key diagnostics for Codex takeover configuration.

## Upgrade and rollback

- X keeps its runtime data under `~/.cc-switch-x` and does not overwrite the
  official `~/.cc-switch` database.
- This beta does not enable the official updater channel.
- The manually built macOS package is unsigned and not notarized. Verify the
  package provenance before opening it and expect a Gatekeeper warning.
