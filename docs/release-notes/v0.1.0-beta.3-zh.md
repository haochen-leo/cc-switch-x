# CC Switch X v0.1.0-beta.3

**发布日期**：2026-09-07

**[English →](v0.1.0-beta.3-en.md) | [日本語版 →](v0.1.0-beta.3-ja.md)**

CC Switch X v0.1.0-beta.3 在 `v0.1.0-beta.2` 基础上继续刷新 Codex
桥接兼容层。

## 本版重点

- 在 Responses、Chat 与 Anthropic 三条桥接路径统一修复独立
  `function_call_output` 回放配对。
- 为本地 compaction 请求增加聚合路由回退。
- 在第三方 Native Responses 路由上将递归的 `automation_update`
  工具 schema 替换为扁平 schema。
- 将 Native Responses 转换逻辑拆分为独立 provider 模块。

## 升级与回滚

- X 的运行数据位于 `~/.cc-switch-x`，不会覆盖官方
  `~/.cc-switch` 数据库。
- 本 Beta 不启用官方自动更新通道。
- 手工构建的 macOS 制品未签名、未公证。打开前请确认制品来源，并预期
  可能出现 Gatekeeper 警告。

完整变更请参阅[更新日志](../../CHANGELOG.md)。
