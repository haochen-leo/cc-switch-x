# CC Switch X v0.1.0-beta.2

**リリース日**: 2026-09-07

**[English →](v0.1.0-beta.2-en.md) | [中文版 →](v0.1.0-beta.2-zh.md)**

CC Switch X v0.1.0-beta.2 は、Codex プロトコル互換性、集約モデル
カタログの整合性、テスト設定の分離を改善するメンテナンス Beta です。

## 主な変更

- 孤立した `codex_app` の `function_call_output` replay に、完全で決定的な
  function-call ペアを補います。
- 公式カタログ項目をそのまま保持し、サードパーティルートには共通の X
  テンプレートを適用します。
- テスト用ホーム変数が一時的に解除されても、実ユーザーディレクトリへ
  書き込まないようにします。
- Codex takeover 設定の route key 診断ログを追加します。

## アップグレードとロールバック

- X の実行データは `~/.cc-switch-x` に保存され、公式版の
  `~/.cc-switch` データベースを上書きしません。
- この Beta では公式 updater チャネルを有効にしていません。
- 手動で作成した macOS パッケージは未署名・未公証です。開く前に配布元を
  確認し、Gatekeeper 警告が表示される可能性を前提としてください。

完全な変更一覧は[更新履歴](../../CHANGELOG.md)を参照してください。
