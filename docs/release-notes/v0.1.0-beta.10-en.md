# CC Switch X v0.1.0-beta.10

This release adds a dedicated GitHub Beta update channel. The app checks for updates on startup and verifies downloaded updates with the X-specific public key. Windows portable builds continue to update manually from the release page.

To upgrade from beta.9 or earlier, download and install this version manually from GitHub Releases first. In-app updates are available after that. Linux AppImage, deb, and rpm installations use their corresponding update packages.

Back up `~/.cc-switch-x` before updating. macOS packages use ad-hoc signing and are not notarized; Windows packages do not have a code-signing certificate, so the operating system may show security warnings.
