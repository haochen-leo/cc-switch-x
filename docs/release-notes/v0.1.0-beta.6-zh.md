# CC Switch X v0.1.0-beta.6

**发布日期**：2026-10-23

**[English →](v0.1.0-beta.6-en.md) | [日本語版 →](v0.1.0-beta.6-ja.md)**

本版基于官方 CC Switch 3.20.4，完整保留 X 的逐条提交历史及本地功能，
统一独立产品标识、数据目录和数据库扩展，并收敛开发与发布分支。

## 本版重点

- **模型聚合与路由保留**：Claude 按角色供应商映射、Codex 多供应商模型聚合、
  逐模型过滤、429 重试、日志与用量统计继续保留。
- **视觉能力与 OCR**：保留逐模型图像能力声明、图像预算和 OCR 缓存。
  DeepSeek V4.1 不再仅因 DeepSeek 前缀而被当作纯文本模型；已知纯文本名单
  与用户显式声明共同决定是否执行图像转文本。
- **协议兼容**：保留 Chat、Anthropic、Responses 桥接、工具搜索契约以及
  Chat/Anthropic 桥接上的 Codex 本地 compaction 处理。
- **X 产品隔离**：应用标识为 `io.github.haochen-leo.ccswitchx`，运行数据位于
  `~/.cc-switch-x`，不直接共用官方 `~/.cc-switch` 数据库。
- **数据库对齐**：共享 schema v20 同时保留官方 MCode 字段和 X OCR 缓存，
  X 独立 schema v2 使用扩展表保存重试配置及导入记录。
- **维护分支**：`main` 用于 X 开发，`release` 用于发布，标签固定发布提交；
  官方 3.20.4 是上游基线，不是 X 的发布版本号。

## 安装与升级

- 本次仅提供 **macOS Apple Silicon（arm64，macOS 12+）** 的 DMG 和 ZIP，
  附 `SHA256SUMS.txt`。不包含 Intel、Windows 或 Linux 安装包。
- 应用使用本地 ad-hoc 签名，**没有 Apple Developer ID 签名或公证**，
  首次打开可能出现 Gatekeeper 警告。请核对来源与 SHA256。
- 已使用 `~/.cc-switch-x` 的用户应先退出应用并备份该目录，再替换应用。
- 旧本地安装若仍使用 `~/.cc-switch`，需先退出应用、备份整个目录，再迁移
  完整数据库及设置；首次启动的只读导入器仅导入部分配置，不迁移全部历史。
  详见[迁移与隔离边界](../cc-switch-x-maintenance-zh.md)。
- 新安装默认代理端口为 `15722`；已有安装可以保留当前端口。
- 本版不启用官方自动更新，也不启用尚未配置独立签名的 X 自动更新。
  回滚前请恢复对应版本的数据备份，不要直接让旧版打开升级后的数据库。

完整历史见[更新日志](../../CHANGELOG.md)与仓库提交记录。
