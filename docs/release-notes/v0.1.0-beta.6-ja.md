# CC Switch X v0.1.0-beta.6

**リリース日**: 2026-10-24

**[English →](v0.1.0-beta.6-en.md) | [中文版 →](v0.1.0-beta.6-zh.md)**

公式 CC Switch 3.20.4 を基盤とし、X の各コミットと既存機能を保持したまま、
アプリ識別子・データ保存先・データベース拡張とブランチ運用を整理しました。

## ハイライト

- Claude の役割別ルーティング、Codex の複数プロバイダ集約、モデル別フィルタ、
  429 リトライ、ログ、利用状況表示を保持。
- モデル別の画像対応宣言、画像予算、OCR キャッシュを保持。DeepSeek V4.1 は
  接頭辞だけではテキスト専用と判定せず、既知の一覧と明示設定で処理を決定。
- Chat・Anthropic・Responses ブリッジ、ツール検索契約、および Chat/Anthropic
  経路の Codex ローカル compaction 処理を保持。
- Bundle ID は `io.github.haochen-leo.ccswitchx`、データ保存先は
  `~/.cc-switch-x`。公式の実行時データベースは共有しません。
- 共有 schema v20 は公式 MCode フィールドと X OCR キャッシュを保持し、
  X 独立 schema v2 は拡張テーブルでリトライ設定とインポート履歴を管理。
- `main` は X 開発用、`release` は公開用で、タグが公開コミットを固定。

## インストールと更新

- 全パッケージは **GitHub Actions で自動ビルド**：macOS Intel + Apple Silicon
  共通 DMG/ZIP（macOS 12+）、Windows x64/ARM64 MSI・ZIP、Linux x64/ARM64
  AppImage・DEB・RPM。`SHA256SUMS.txt` を同梱します。
- macOS は ad-hoc 署名のみで、**Apple Developer ID 署名・公証はありません**。
  Windows もコード署名なしです。配布元と SHA256 を確認してください。
  OS のセキュリティ警告が出る場合があります。
- 更新前にアプリを終了し、`~/.cc-switch-x` 全体をバックアップしてください。
- 旧ローカル版が `~/.cc-switch` を使用している場合、終了・全体バックアップ後に
  データベースと設定を完全移行してください。初回の読み取り専用インポートは
  一部設定のみで、全履歴の移行ではありません。
- 新規インストールの既定ポートは `15722`。既存環境は使用中のポートを維持可能。
- 自動更新は無効です。旧版へ戻す際は対応するデータバックアップも復元してください。

詳細は[メンテナンス方針](../cc-switch-x-maintenance.md)とコミット履歴を参照してください。
