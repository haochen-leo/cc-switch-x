# CC Switch X v0.1.0-beta.4

**リリース日**: 2026-09-13

**[English →](v0.1.0-beta.4-en.md) | [中文版 →](v0.1.0-beta.4-zh.md)**

CC Switch X v0.1.0-beta.4 は Codex の共通設定を公式プロバイダ配下に統一し、
プロキシの対応範囲を Codex 画像エンドポイントへ拡大するとともに、
上流 CC Switch のベースラインを v3.20.2 系まで同期しました。

## ハイライト

- Codex の共通設定が公式プロバイダに統一されました。起動時に
  ライブ取得（汚染防止ガード付き）し、UI では公式設定が読み取り専用に
  なり、ライブ書き換え時もデータベース管理外の `mcp_servers` が
  保持されます。
- プロキシが Codex の image generations / image edits エンドポイントに
  対応しました。
- 集約の安全性向上：集約が有効な間はプロバイダ切り替えを無効化し、
  組み込みの公式シードプロバイダは削除不可になりました。テイクオーバー
  中の Codex `/v1/models` プローブは公式バックエンドへ中継されます。
- 同期リプレイが終端状態と整合するようになり、重複していた Mac の
  raw-relay 画像ルートは上流のスタンドアロンパススルーに一本化されました。
- 上流同期：SoleAPI、9527CODE、AICodeWith、QwenCloud、Tencent
  TokenHub / Token Plan のプリセット追加、PPIO Pi プリセット拡充、
  2026 年 9 月の価格表更新（GPT-6 Astra、GLM-5.3 / GLM-5.3 Flash、
  Gemini 3.8 Flash、Claude Fable 5.1 / Mythos 5.1）、Grok/xAI Native
  Responses の修正、Codex OAuth の並列ツール呼び出し、アップデート失敗時の
  理由表示、および i18n / アクセシビリティの各種修正。

## アップグレードとロールバック

- X の実行データは `~/.cc-switch-x` に保存され、公式
  `~/.cc-switch` データベースを上書きしません。
- 本ベータでは公式の自動更新チャネルは有効になりません。
- 手動ビルドの macOS パッケージは署名・公証されていません。開く前に
  パッケージの出所を確認し、Gatekeeper の警告が表示されることを
  想定してください。

変更の完全な一覧は[更新履歴](../../CHANGELOG.md)を参照してください。
