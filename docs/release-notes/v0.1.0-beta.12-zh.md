# CC Switch X v0.1.0-beta.12

本版修复 X 接管后旧 Codex 会话报「模型提供商不可用」的问题，并补齐两处 Responses 链路兼容。

- 修复历史会话失联：导入旧 CC Switch 数据后立即刷新设置缓存，统一开关不再被误读为关闭；接管不再生成 `cc-switch-x-official` / `cc-switch-official`，官方接管在统一关闭时使用内建 `openai` 桶（`openai_base_url` 改道），统一开启与聚合路由统一使用 `custom` 桶。旧官方桶历史会迁移到当前活跃桶；所有启动历史迁移排在崩溃/接管恢复之后，统一迁移支持启动重试与快速路径，同一秒连续迁移保留首个数据库备份。切换供应商出现跨桶时给出提示，迁移完成后提示重启 Codex 解锁旧会话。
- 修复向 OpenAI 上游回放第三方 reasoning 密文导致的 `400 invalid_encrypted_content`：仅对 OpenAI 目标移除非 OpenAI 密文（保留摘要），第三方上游不受影响。
- 规范化超长的 Responses item / call ID，避免上游拒绝请求。

数据库结构、代理协议和端口不变。升级前退出 CC Switch X，备份整个 `~/.cc-switch-x`；首次启动完成历史迁移后按提示重启 Codex。
所有安装包由 GitHub Actions 构建并提供 `SHA256SUMS.txt`。macOS 使用 ad-hoc 签名、未公证；Windows 安装包尚未使用代码签名证书。
