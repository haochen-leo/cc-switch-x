# CC Switch X v0.1.0-beta.8

本版修复 Codex 多模型聚合中官方目录长期停留在旧客户端小目录的问题。

- 请求版本按本机 PATH CLI、近期线程和 Codex 原生缓存的客户端版本取语义版本较新者，不升级 CLI、不写死请求版本。
- 用当前登录在线获取官方目录；X 成功快照绑定用户、workspace 和客户端版本。原生 `models_cache.json` 仅提供版本线索，不混用其模型列表，也不修改原生缓存。
- 菜单、聚合文件、路由和发布基线使用同一成功快照；发布失败不推进基线，下次目录无变化仍可重试。
- 显示可见官方模型数，明确排除项另计；保留已有排除选择。官方删除模型后以最新成功目录为准。

数据库结构、代理协议和端口不变。升级前退出 CC Switch X，备份整个 `~/.cc-switch-x`。
安装后 X 会刷新并发布聚合目录；已运行的 Codex 若未重新读取静态目录，需要在合适时机新开客户端，勿中断正在执行的会话。

所有安装包由 GitHub Actions 构建并提供 `SHA256SUMS.txt`。macOS 使用 ad-hoc 签名、未公证；自动更新仍关闭。
